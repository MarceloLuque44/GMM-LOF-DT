#BITACORA
ID / Paso (#)	Número secuencial del cambio o de la regla aplicada.
Fecha / Hora	Fecha y hora en que se ejecutó la acción de limpieza.
Responsable	Nombre o usuario del analista o científico de datos que realizó la modificación.
Dataset	Nombre exacto del conjunto de datos afectado.
Atributo / Variable	Nombre exacto de la columna o campo afectado.
Tipo de problema	Clasificación de la anomalía: valor nulo, duplicado, outlier, inconsistencia de formato, error tipográfico, entre otros.
Metodología	Etapa del proceso de limpieza en la que se realizó la modificación.
Acción realizada	Descripción precisa de la técnica aplicada, por ejemplo, imputación por mediana, eliminación de filas, recodificación o eliminación de espacios.
Criterio / Justificación	Explicación de la razón por la que se tomó la decisión, considerando reglas de negocio o criterios metodológicos.
Filas afectadas (N)	Cantidad exacta de registros que sufrieron alguna modificación o eliminación.
Impacto en el dataset	Cantidad de registros existentes antes y después de aplicar el cambio.
Código / Script	Función, consulta o línea de código utilizada en Python, R o SQL.
